# Frisbee-App

Web-App für die Fang-Erkennungs-Frisbee (Seeed XIAO nRF52840 Sense Plus).
Verbindet sich per Web-Bluetooth (Chrome auf Android) mit der Frisbee, zeigt den
Zustand live (launch / fly / catch / hol / touch) und erkennt das gesprochene Wort
mit Whisper direkt im Browser.

Live: https://bratislavski.github.io/frisbee-app/

```
npm install
npm run dev     # lokal
npm run build   # baut nach dist/
```
